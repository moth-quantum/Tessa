# figures/paper/ - the figures exactly as used in the paper (reference copies)

Unmodified copies of the files the paper includes (`\includegraphics` / `\input`), for
comparison with the figures the notebook and `scripts/make_all_figures.py` write to `figures/`.
Do not overwrite them. How far each one is regenerated, and with which matplotlib version it is
pixel- or byte-identical, is listed in [REPRODUCIBILITY.md](../../REPRODUCIBILITY.md), sections (a)
and (e).
